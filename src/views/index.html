        Simulate delivery failures
        
                    
        Send to one of these special recipients to see how your app handles a refusal. The part after + (or ., _, -) is ignored, so reject+signup@example.com works too. Turn this off with SMTP_SIMULATE=false.
        
                    
        
                        
        reject@550 mailbox unavailable (permanent failure)
        
                        
        tempfail@451 temporary failure, try again later
        
                        
        full@452 mailbox full
        
                        
        slow@Accepted after 5 seconds. slow10@ waits 10 seconds (at most 30)
        
                        
        datafail@The recipient is accepted, then the message is refused with 554 and not stored
        
                    
        
                    
        Other recipients on the same message are still accepted, as with a real server.
        
                
        

                
        
                    
        Read emails from scripts and tests
        
                    
        Send Authorization: Bearer <key> (or X-API-Key) with a Read key from the API keys page, or ADMIN_TOKEN (everything, including delete). Tests can use the client/ helper (waitForCode, waitForLink); see the README.
        
                    
        
                        
        GET/api/emails/latest?to=…
        Newest matching email with its body, or 404. Includes code (the detected one-time code, or null) and links (every http(s) link)
        
                        
        GET/api/events
        Server-Sent Events for both channels: an email event (the summary) per email and an sms event (phone masked, with its code) per SMS stored from now on. The dashboard uses it to update live
        
                        
        GET/api/emails/export?ids=1,2,3
        A zip of the original .eml files (up to 100 emails)
        
                        
        GET/metrics
        Prometheus metrics (emails received, rejections, webhook and relay results, stored emails). Same access as reading emails
        
                        
        GET/api/emails/wait?to=…&timeout=30
        Waits for a matching email (one that is already stored is returned at once), or answers 408. Same body as /latest; timeout is 1–120 seconds
        
                        
        GET/api/emails
        Summaries without bodies. Filters: search, to (exact address), from, subject, startDate, endDate, after, before, page, pageSize (max 100)
        
                        
        GET/api/emails/:id
        One email: text, html, headers, attachments (each with a download url), code, links and deliverability checks
        
                        
        GET/api/emails/:id/thread
        The emails in the same conversation (Message-ID, In-Reply-To, References), oldest first
        
                        
        POST/api/emails/:id/check-links
        Admin. Requests each link in the email and reports its status
        
                        
        GET/api/emails/:id/raw
        The original message (add ?download=true for an .eml file)
        
                        
        DELETE/api/emails/:id
        
                        
        DELETE/api/emails with { "ids": [1, 2] }, or /api/emails?to=user@example.com to empty one inbox
        
                        
        GET/health
        Public; { "status": "ok" } when the database is reachable

        Send an SMS
        
                    
        The SMS gateway: point your application's SMS integration at this endpoint instead of a real provider. Nothing is delivered to a phone.
        
                    
        
                        POST
                        /api/sms
                        
                    
        

                    
        Headers
        
                    
        
                        
        Content-Typeapplication/json
        
                        
        X-API-KeyA Send key from the API keys page
        
                        
        AuthorizationOr, for clients that can't set custom headers: Bearer <Send key>
        
                    
        

                    
        Body
        
                    
        
                        
        senderOptional, up to 64 characters
        
                        
        phoneRequired. 6–15 digits, optional leading +. Spaces, dashes, dots and brackets are removed.
        
                        
        messageRequired, up to 1600 characters
        
                    
        

                    
        
                        
        Example
        
                        
                    
        
                    
        

                    
        Responses
        
                    
        
                        
        201Stored. Returns { success, id, timestamp }
        
                        
        400Invalid input; details lists the problem per field
        
                        
        401Missing or unknown API key
        
                        
        429Rate limit exceeded (SMS_RATE_LIMIT)
        
                    
        
                
        

                
        
                    
        Read SMS from scripts and tests
        
                    
        Send Authorization: Bearer <key> with a Read key (a Read key limited to some email inboxes can't read SMS) or ADMIN_TOKEN. Phone numbers are masked unless you add unmask=true.
        
                    
        
                        
        GET/api/sms/latest?phone=…
        Newest matching message, or 404. Includes code: the detected OTP, or null
        
                        
        GET/api/sms/wait?phone=…&timeout=30
        Waits for a matching message (one already stored is returned at once), or answers 408
        
                        
        GET/api/sms
        search, phone, startDate, endDate, after, before, page, pageSize (max 100)
        
                        
        DELETE/api/sms/:id, /api/sms with { "ids": [1, 2] }, or /api/sms?phone=… to empty one number. Admin only
        
                    
        

                    
        
                        
        Read the latest OTP
